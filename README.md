# CDAC_DESD_AUG2025_GROUP7
Final project of CDAC BANGALORE, PG-DESD Course group 7 started on Aug 2025. Aim of the project is to create a machine learning algorithm for detecting and predicting a particular action based on the readings of the IMU sensor.
Hardware :- STM32M4F429ZI Discovery 1 Cortex M4 Processor, 7Semi BNO086 IMU sensor, Breadboard, Wiring connections, Digital Discovery Logic Analyzer.
Software :- Zephyr RTOS, CubeIDEMx, VSCode, LVGL Library for Graphics, TinyML for Machine Learning Projects. 

References:- Technical Reference Manual, User Guide
